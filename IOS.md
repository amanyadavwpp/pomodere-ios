# Pomodere on Your iPhone 15

The web application is prepared for an offline Capacitor 8 iOS wrapper. The iPhone 15 uses a 393 x 852 CSS-point portrait viewport; layouts are fluid rather than hard-coded to that size.

This repository is source code, not a signed IPA. An IPA is not made by renaming a ZIP file. A Mac, Xcode, Apple signing, and an appropriate installation method are still required. Native compilation, signing, notifications, and physical-device behavior have not been verified in this environment.

## Included

- A Notes tab beside Your progress, with an encrypted notebook and one password for all notes.
- AES-256-GCM encryption of titles and text, with PBKDF2-SHA-256 at 600,000 iterations, a random salt, and a fresh IV for each save.
- Password setup, unlock, change password, encrypted autosave, manual save, search, note deletion, and encrypted JSON backup/restore.
- Automatic notebook locking when leaving Notes, when the app becomes inactive, and after 5 minutes without interaction.
- Native Preferences storage instead of relying on the iOS WebView's localStorage.
- Offline bundled fonts, illustrations, JavaScript, CSS, and generated ambient sound. The packaged app does not need a hosted website or a development server.
- Safe-area spacing for the Dynamic Island and home indicator, larger touch controls, 16px form fields to avoid iOS input zoom, and keyboard-aware dialogs.
- Opt-in native notifications for the active timer session. Enable Timer reminders in Preferences on the iPhone build.
- A native app-switcher privacy cover, icon source, and Apple privacy-manifest template, installed by the preparation script.

## Requirements

- macOS with Xcode 26.0 or newer and its command-line tools.
- Node.js 22 or newer. `.nvmrc` selects Node 22 if you use nvm.
- Your Apple ID and an appropriate development or distribution signing team.
- An iPhone 15 running iOS 17 or newer. Keep iOS and Xcode up to date.

Capacitor 8 uses Swift Package Manager by default. CocoaPods is not needed for the default setup below.

## First Build

1. Download the whole project, including `public`, `resources`, `scripts`, `ios-support`, and `capacitor.config.ts`. Do not copy another computer's `node_modules`; install dependencies on your Mac.
2. In `capacitor.config.ts`, change `appId` from `com.pomodere.focus` to a unique reverse-domain identifier you can sign, for example `com.yourname.pomodere`. Keep the identifier consistent for future updates. Set this before generating the iOS project.
3. Open Terminal in the project folder and run:

```sh
npm install
npm run build
npx cap add ios
node scripts/prepare-ios.mjs
npx cap sync ios
npx cap open ios
```

Run `npx cap add ios` only once. It generates the actual native Xcode project on your Mac. Do not set `server.url`, change the localhost origin, or package the Vite development server. `webDir: 'dist'` bundles the production application.

The preparation script adds a privacy-shield observer to the generated AppDelegate, calls it from the existing launch method, and backs up the original. It preserves Capacitor's AppDelegate and SceneDelegate behavior. It observes both app and scene lifecycle notifications, including the scene-based template in Capacitor 8.5. On a customized native project, review the diff or merge `ios-support/PrivacyShield.swift` manually. The script is intended for the new project generated by the instructions above.

## Xcode Setup

1. Select the App target. Under Signing & Capabilities, choose your team, enable Automatically manage signing, and confirm the bundle identifier matches the one you chose.
2. Set the App target's minimum iOS deployment version to 17.0 or newer. The web UI targets modern Safari features supported by the iPhone 15.
3. Use File > Add Files to App to add `ios/App/App/PrivacyInfo.xcprivacy`. Check the App target in Target Membership and confirm the file appears in Build Phases > Copy Bundle Resources. Copying a file into the folder alone does not register it with Xcode.
4. Confirm `AppDelegate.swift` is in the App target and the generated tomato icon appears under Assets > AppIcon. The script sets light appearance and view-controller-based status bar handling in Info.plist.
5. Connect your iPhone, trust the Mac, enable Developer Mode when requested, select your iPhone as the run destination, and press Run.

The privacy manifest declares UserDefaults usage with reason CA92.1 and file timestamps with reason C617.1, as required by the official Preferences and Filesystem plugins. Review the manifest if you add other plugins or data collection later. No push-notification entitlement or remote server is required for local timer reminders.

## Install or Export an IPA

For personal testing, Xcode can install the development build directly on your connected phone. A free Personal Team can have provisioning limits and require periodic re-signing; it is not the same as a general-purpose distributable IPA.

For a distributable build, choose a generic iOS device destination, use Product > Archive, and then Distribute App in Organizer. Select a method supported by your Apple Developer account and provisioning profile. TestFlight is a straightforward option with a paid Apple Developer Program membership. Development or Ad Hoc exports must be signed for the allowed device(s).

An unsigned IPA cannot be installed simply by downloading it in Safari. Use Xcode, TestFlight, or another installation/signing workflow you are authorized to use. Keep certificates and passwords out of this repository.

Because Notes uses encryption, answer App Store Connect's encryption/export-compliance questions according to Apple's current guidance. This project deliberately does not hard-code an exemption declaration for you.

## Move Your Notes

1. In the current browser, open Notes, create or unlock your notebook, and wait for Saved & encrypted.
2. Select Export backup and save the encrypted JSON file somewhere you control.
3. Move the backup to Files on your iPhone, for example using AirDrop or iCloud Drive.
4. Open Notes in the installed app, select Restore backup, choose the file, and enter the password used for that backup.

Restoring replaces the entire notebook on that device after password verification and explicit confirmation. Downloading source files does not download browser data. Browser and native-app storage are separate. The backup transfers Notes only; existing tasks, settings, and progress do not automatically move between installations.

Exports remain encrypted, including the temporary file used by the native share sheet. Changing your password does not update older backups: they still need their old password. The app cannot recover a forgotten password. Uninstalling, clearing app data, or losing your device can remove your notebook, so keep backups. The app itself does not provide cloud sync; iOS device-backup behavior is controlled by your system settings.

Notes is intentionally a lightweight text notebook: up to 50 notes, 12,000 characters per note, and 120,000 total title/body characters. It has no attachments. Passwords and non-extractable encryption keys are not persisted by the app. Unlocking makes plaintext available in memory for editing; this is encryption at rest, not protection from a compromised device, malicious same-origin code, screenshots taken while unlocked, or a compromised keyboard. JavaScript cannot guarantee immediate erasure of every garbage-collected string.

## Timer Behavior on iOS

iOS suspends WebView JavaScript when the app is backgrounded. Pomodere stores a wall-clock deadline and schedules a native reminder for the current session, so it does not pretend that JavaScript keeps running in the background.

Enable Timer reminders in Preferences and allow notifications. Pausing, resetting, changing mode, or skipping cancels/replaces the pending reminder. Notifications contain only generic timer text, never note text or task titles. Sound and delivery follow iPhone notification permissions, the silent switch, and Focus settings. The foreground app uses its own completion chime instead of duplicating the native notification presentation.

When you reopen the app after a deadline, the session is recorded once and the next timer becomes ready. Auto-start settings apply when the app is active again; the app does not record a series of imagined focus sessions while suspended. Ambient audio is intended for foreground use and is not configured for continuous background playback.

## Update an Existing App

Keep the same bundle identifier and signing identity. Export a notebook backup before upgrading. After changing web code, run:

```sh
npm run build
npx cap sync ios
npx cap open ios
```

Build and install the update from Xcode. Do not uninstall the old app just to update it, because uninstalling removes its data. Commit the generated `ios` directory after completing the native setup so that future builds retain signing configuration, native assets, and target membership.

## Verify Before Relying on It

- Create a notebook, save a note, force-close and reopen, and confirm the correct password unlocks it while a wrong password does not.
- Inspect an exported backup: it must contain ciphertext and encryption metadata, not note titles, text, or a password.
- Test changing passwords, then export a new backup and restore it into a fresh test installation.
- Switch away from Notes, open the app switcher, lock the phone, and return. Confirm the native privacy cover hides the snapshot and the notebook requires its password again.
- Check portrait, landscape, larger accessibility text, the keyboard, the Dynamic Island, the home indicator, and the native share/file-picker sheets on the actual iPhone.
- With a one-minute test timer, enable reminders, lock the phone, and confirm the reminder arrives. Repeat with pause/reset/skip and with notifications denied.
- Reopen after the timer has expired and confirm exactly one completed focus session was recorded. Check short and long breaks and auto-start preferences.
- Launch in Airplane Mode and verify the fonts, illustration, Notes, and timer still work.
- Wait for Saved & encrypted before force-closing. If a save fails, leave the app open, unlock if necessary, free space, and retry; unsaved recovery data exists only in memory. While unlocked, Export backup can also rescue the latest edits even if the device cannot persist them.
- Do not edit the same browser notebook in two windows at once. Stale saves are rejected rather than silently overwriting another window's edits or password. If you see a conflict, export the current edits as an encrypted backup before reloading.

Crypto regression tests are supplied in `tests/notebook.test.mjs`. With Node 22.18 or newer, run `node --experimental-strip-types --test tests/notebook.test.mjs`. Run `npx tsc --noEmit` for a separate TypeScript check. These are in addition to, not substitutes for, physical-device and Xcode tests.
